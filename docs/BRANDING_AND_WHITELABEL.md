# The Void AI Orchestration System — Branding and White Label

## Default Brand
- Product: The Void AI Orchestration System
- Owner: ZQM Computing LLC
- Support: zqmcomputing@gmail.com
- Portal docs: /docs

## Customer White Label
- Customer name and support email are injected via `.env`
- Default UI title and footer are loaded from settings
- Customer logos can be mounted into the Docker web containers
- Custom domain is configured through Traefik labels and TLS provider

## Assets Provided
- Default logo placeholder paths documented in `docs/CUSTOMER_INSTALL.md`
- HTML diagrams and 3D explorer included for customer onboarding
- Optional embedded chat UI styling is available via Open WebUI / Chatbot UI themes

## Restrictions
- ZQM Computing LLC branding must remain in the footer unless a white-label
  amendment is signed.
- The commercial license file must be distributed with every customer copy.
